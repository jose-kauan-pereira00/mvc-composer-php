 # PHP Compose

Projeto de estudo para praticar a configuração e a execução de uma aplicação PHP utilizando Docker Compose.

## Sobre o projeto

Este repositório reúne exemplos e configurações para aprender a criar um ambiente de desenvolvimento PHP com serviços containerizados. A proposta é facilitar a prática de conceitos como:

- criação e gerenciamento de containers;
- configuração de serviços com Docker Compose;
- integração entre PHP e outros serviços necessários à aplicação;
- organização de um ambiente de desenvolvimento reproduzível.

## Observação

Este projeto é **apenas para treino** e foi desenvolvido com base em um curso. Portanto, o código pode ser simples, experimental ou não estar pronto para uso em produção.
